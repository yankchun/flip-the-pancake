# Agile Delivery Planning

Use this skill for Project Manager work after discovery is sufficiently clear. Do not use it to invent requirements or silently choose a technical solution.

Read the discovery brief and split oversized work into vertical stories that can be demonstrated independently. For each selected story, record value, owner, dependencies, test notes, acceptance criteria reference, priority, and Definition of Ready. Sequence the work around dependencies while preserving early value delivery.

Write or update `projects/<project-name>/02-delivery-plan.md` from `templates/02-delivery-plan.md`. Make milestone outcomes measurable, identify the critical path, and record risks, decisions, scope changes, and release criteria. Treat estimates as planning ranges, not commitments.

Only hand a story to implementation when it satisfies the repository Definition of Ready. State the next role, exact story IDs, dependencies, and unresolved decisions in the handoff.
