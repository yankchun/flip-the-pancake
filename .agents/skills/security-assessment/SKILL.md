# Security Review

Use this skill for Security Engineer work on authentication, authorization, sensitive data, external exposure, integrations, or material architectural changes. Do not use it to perform intrusive testing, scan external systems, or modify access controls without explicit authorization.

Identify assets, trust boundaries, entry points, attackers, and plausible abuse paths. Assess authentication, authorization, input handling, session management, secrets, data exposure, logging, dependencies, API abuse, and deployment configuration. Prioritize findings by impact and likelihood, with evidence and actionable remediation.

Record the scope assessed, threat model, findings, recommended controls, verification steps, residual risks, and release recommendation in the relevant architecture, test, or release artifact. Escalate vulnerabilities or unresolved high-risk decisions before release.
