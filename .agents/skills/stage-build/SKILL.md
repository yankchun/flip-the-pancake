# Development Stage

Use this stage only for stories that meet the Definition of Ready. Frontend and Backend Developers own their relevant work; Tester prepares or extends coverage alongside implementation. Involve DevOps only when build, environment, or deployment implications need design.

Use `frontend-implementation`, `backend-implementation`, `project-traceability`, and `project-state`. Preserve approved scope and contracts. Do not deploy, change production data, or start unrelated work without switching stages.

Conclude with the implemented increment, relevant checks and results, remaining risks, and a recommendation to exit or move to Verification.
