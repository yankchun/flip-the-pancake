# Verification Stage

Use this stage to validate completed stories against their acceptance criteria and regression risk. Tester leads. Involve the Security Engineer for material security changes and developers only to investigate or remediate verified issues.

Use `test-verification`, `security-assessment`, `project-traceability`, and `project-state`. Do not change product behavior just to make a test pass; record defects and evidence instead.

Conclude with test evidence, defect disposition, residual risks, and a release recommendation or a recommendation to return to Development.
