# Architecture Stage

Use this stage for selected ready stories that change components, data, APIs, integrations, or material quality attributes. The Solution Architect leads. Involve the Security Engineer for material risk; consult relevant developers for implementation constraints.

Use `solution-architecture`, `security-assessment`, `project-traceability`, and `project-state`. Evaluate tools only when a decision is needed, and do not commit to vendors, paid services, or external accounts without user approval.

Conclude with recorded technical decisions, interfaces, risks, implementation order, and a recommendation to exit or move to Development.
