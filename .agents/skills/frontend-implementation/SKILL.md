# Frontend Delivery

Use this skill for Frontend Developer work on a story that meets the Definition of Ready. Do not use it to redefine product scope or alter backend contracts without coordination.

Inspect existing UI conventions, relevant flows, and the approved acceptance criteria before editing. Establish component boundaries, client state, data contract assumptions, and the loading, empty, error, permission, and recovery states that apply. Implement the smallest maintainable change consistent with the existing design system.

Validate the changed experience with the most relevant automated checks and browser-based verification when available. Record changed files, behavior covered, API assumptions, checks run and their results, remaining UI risks, and the next handoff to `tester`.
